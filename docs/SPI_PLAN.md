# SPI Master and Slave on the Protocol Engine — Design and Status

Status (2026-10-11): **implemented and verified in simulation only**, all 4 modes, both roles, at engine level and on the
full chip through the management SPI link. No FPGA work. Test results and measured limits: [SPI_RESULTS.md](SPI_RESULTS.md).

SPI here is **firmware on an engine**, like UART. The hardware `spi_slave` in `src/` is the management link (fixed
mode 0) and is not part of this work.

## Decisions (agreed 2026-10-11)

1. Add a pin-conditional jump to the ISA (needed so a slave can see CS go inactive mid-frame).
2. No loopback and no RTL for it now: the chip is verified as master and as slave independently, over the host link.
3. 1..32 bits per CS frame for v1 (one FIFO word per frame).

## ISA addition: `JPH` / `JPL`

| Opcode | Mnemonic | Operand | Effect | Cycles |
|---|---|---|---|---|
| 17 | `JPH p, a` | `[8:6]` pin, `[5:0]` addr | jump to `a` if `pin_in[p] == 1`, else advance | 1 |
| 18 | `JPL p, a` | `[8:6]` pin, `[5:0]` addr | jump to `a` if `pin_in[p] == 0`, else advance | 1 |

`pin_in` is the synchronized input (2 clocks old), as for `WAITH`/`WAITL`. Opcodes 17/18 were reserved (`WAITR`/`WAITF`,
no longer needed); 19..31 still trap. RTL change: `src/isa.vh` (2 defines), `src/control_unit.v` (1 wire, 4 lines).
Encoding: `word = op << 27 | pin << 6 | addr`.

## Pins, modes, data layout

Pins (same numbers in both roles): `2` SCLK, `3` MOSI, `4` MISO, `5` CS (active low).

| Mode | CPOL | CPHA | Sample edge | Shift edge |
|---|---|---|---|---|
| 0 | 0 | 0 | rise (leading) | fall (trailing) |
| 1 | 0 | 1 | fall (trailing) | rise (leading) |
| 2 | 1 | 0 | fall (leading) | rise (trailing) |
| 3 | 1 | 1 | rise (trailing) | fall (leading) |

One FIFO word per CS frame of `n` bits (1..32). Host TX word: MSB-first `v << (32-n)`, LSB-first `v`.
Host RX value: MSB-first `w & (2^n-1)`, LSB-first `w >> (32-n)`. (`spi_prog.tx_word` / `rx_value`.)

## Firmware

Generated by [`host/spi_prog.py`](../host/spi_prog.py) (`master(mode, bits, lsb, h)`, `slave(mode, bits, lsb)`);
`python host/spi_prog.py` prints all 8 listings. CPOL only swaps which pin instruction makes each edge; CPHA changes the
order. Listings for mode 0 are in [../instructions.md](../instructions.md) §3.

**Master** (17 words CPHA=0, 18 words CPHA=1). Init sets the idle levels *before* driving the pins (no CS/SCLK glitch).
Per frame: `PULL`, `SETL n`, CS low, bit loop, CS high, `PUSH`. Bit loop:
CPHA=0 `OUT1 H; lead; IN1 H; trail; DJNZ` — CPHA=1 `lead; OUT1 H; trail; IN1 H; DJNZ` (plus `WAIT H` after CS low).
Timing, exact for every mode: lead phase `H+2` clocks, idle phase `H+3`, CS to first edge `H+2`, period `2H+5`.
The master never loses data: with no TX word it parks in `PULL` and with a full RX FIFO in `PUSH`, both with CS high
and SCLK idle.

**Slave** (18 words CPHA=0, 16 words CPHA=1).
```
top:  WAITH CS ; DIRI MISO ; PULL ; SETL n ; WAITL CS ; [CPHA=0: OUT1 0] ; DIRO MISO
CPHA=0:  b: JPH CS,top ; Jx SCLK,b ; IN1 0 ; DJNZ c ; PUSH ; JMP top
         c: JPH CS,top ; Jx SCLK,c ; OUT1 0 ; JMP b
CPHA=1:  b: JPH CS,top ; Jx SCLK,b ; OUT1 0 ; c: JPH CS,top ; Jx SCLK,c ; IN1 0 ; DJNZ b ; PUSH ; JMP top
```
- Every edge wait is a 2-instruction poll that also checks CS: CS inactive mid-frame (abort, short CS pulse) jumps to
  `top`: MISO released, no `PUSH`, next frame starts clean. The aborted frame's TX word is consumed and nothing is pushed.
- `WAITH CS` first also hides the synchronizer's reset value 0 (CS would look active right after RUN; same trap as UART RX).
- CPHA=0 ends at the last sample (no wait for the last trailing edge), so CS may rise right after the last SCLK edge.
- Partial ISR bits after an abort are harmless: the host extracts exactly `n` bits.

## Host rules (slave role)

The slave cannot pause its master. The host must keep the TX FIFO non-empty before every CS fall (else the frame is
missed: MISO stays released) and drain the RX FIFO (else `PUSH` blocks and later frames are missed). Both failures are
detected by the tests, not hidden.

## Verification method (summary; details in SPI_RESULTS.md)

Python reference waveform + **independent bus decoder** (knows only the mode table, not the firmware) + Verilog
**peers** (4-mode master and slave models written from the mode table) + the real RTL in Icarus. The testbench logs every
change of CS/SCLK/MOSI/MISO; Python rebuilds the frames, checks bus rules and timing, and compares data end to end.

| File | Role |
|---|---|
| `host/spi_prog.py` | firmware generator, host data layout helpers |
| `host/spi_test.py` | runner: phases `selftest peers master slave chip mutants`, decoder, checks, sweeps |
| `tb/spi_peer.vh` | Verilog SPI master model + slave model (all modes), pad logger |
| `tb/tb_spi_engine.v` | engine_top + direct FIFO host (roles: master, slave, peers only) |
| `tb/tb_spi_chip.v` | full chip; host only through the management SPI link (`tb/spi_master.vh`) |

Run: `python host/spi_test.py` (all phases, about 5.5 min) or name phases. Prints `RESULT spi_test: PASS|FAIL`.

## Not done / open

- Loopback (engine 0 master ↔ engine 1 slave on the same pads): deferred by decision 2.
- Frames longer than 32 bits per CS; continuous CS-held streaming.
- Real-silicon timing (pad delays, synchronizer metastability) is outside zero-delay simulation; limits are in clocks.
